Research

Published at ACIIDS 2026 (Springer Singapore), as part of my M.E. thesis at Jadavpur University.

An Attention-Enhanced Architecture with Multi-Objective Hyperparameter Optimization for Efficient Lung Segmentation

Lung segmentation from chest X-rays is the first step in many automated diagnosis pipelines, and it has to be accurate and cheap to run. I built EC-CBAM-UNet, a U-Net with attention modules that help the network focus on the informative channels and regions of the image. I then tuned its hyperparameters with a multi-objective search, so that accuracy and efficiency were optimized together rather than traded off by hand.

Supervised by Dr. Ujjwal Maulik (Jadavpur University) and Dr. Jamuna Kanta Sing, with the ISI–JU–CNCI collaboration.

  • TaskLung segmentation on chest X-ray images
  • ModelEC-CBAM-UNet, a U-Net with channel and spatial attention
  • MethodMulti-objective hyperparameter optimization
  • Built withPyTorch

Smart Attendance System using Face Recognition

Problem: manual roll calls waste class time and are easy to fake.

Distributed Task Queue System

Problem: slow jobs should not block the API that requests them.

Approach: FastAPI accepts tasks and puts them on a Redis queue. Separate worker containers pick them up, and WebSockets push live status back to the client.

Python, Redis, FastAPI, Docker, WebSockets
