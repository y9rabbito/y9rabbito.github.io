# Portfolio: Sudipta Kumar Biswas

A single-file static site. Everything (HTML, CSS, JS) is in `index.html`.

## Deploy free on GitHub Pages
1. Create a new GitHub repo, e.g. `portfolio` (or `<username>.github.io`).
2. Upload `index.html` to the repo root.
3. Go to Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site goes live at `https://<username>.github.io/portfolio/`.

## Netlify / Vercel
Drag and drop the folder containing `index.html` into app.netlify.com/drop, or import the repo on Vercel.

## Edit before publishing
- Add your GitHub and LinkedIn links in the nav and footer.
- Add a CV: put `cv.pdf` beside `index.html` and add a link such as `<a class="btn" href="cv.pdf">Download CV</a>`.
- Add real figures from your paper, with a link to it, in the Research section.
- Add repo links and screenshots to each project.
- Turn a "Currently exploring" concept into a full project once you have built it.
